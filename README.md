# Single-Page CV

A simple, semantic, single-page Curriculum Vitae (CV) built using plain HTML5.

This project was developed as part of the HTML Fundamentals learning path on [roadmap.sh](https://roadmap.sh/projects/single-page-cv), with a focus on understanding HTML document structure, semantic elements, and SEO fundamentals.

## Live Demo

[View the Live CV](https://7amarah.github.io/plain-html-single-page-cv/)

## Project Overview

The objective of this project is to create a structured, accessible, and search-engine-friendly CV webpage using only HTML, without relying on CSS frameworks or JavaScript.

The webpage presents professional information in a clear and organised format.

## Features

- Semantic HTML5 document structure.
- Proper heading hierarchy.
- Structured sections for skills, education, and professional experience.
- Contact information and professional profile links.
- Basic SEO metadata.
- Open Graph metadata for social media sharing.
- Responsive viewport configuration.

## Technologies Used

- HTML5
- Semantic HTML
- SEO metadata
- Open Graph metadata

## Getting Started

### Prerequisites

You only need:

- A web browser.
- A code editor (such as Visual Studio Code).
- Git (optional, for cloning the repository).

### Running Locally

1. Clone the repository:

   ```bash
   git clone git@github.com:7amarah/plain-html-single-page-cv.git
   ```

2. Navigate into the project directory:

   ```bash
   cd plain-html-single-page-cv
   ```

3. Open `index.html` directly in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the webpage.

No package installation, build process, or development server is required.

## Deployment

The project is hosted using GitHub Pages.

To deploy:

1. Push the project files to the `main` branch of the public GitHub repository.
2. Navigate to the repository's **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)` as the deployment source.
5. Save the configuration.

GitHub Pages will publish the webpage.
